# FASTA Sequence Analyzer

## Overview

The FASTA Sequence Analyzer is a Python program that reads DNA sequences from a FASTA file and performs basic sequence analysis. It is designed for beginners learning bioinformatics and file handling in Python.

## Features

- Read DNA sequences from a FASTA file
- Display the sequence ID
- Calculate sequence length
- Count nucleotides (A, T, G, C)
- Simple and beginner-friendly
